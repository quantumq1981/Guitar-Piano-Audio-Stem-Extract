# inbox: drop songs here to separate them

1. On github.com (works in a phone browser), open this `inbox` folder.
2. Tap **Add file → Upload files**, pick a song (mp3, wav, flac, m4a, aac or ogg), then tap **Commit changes**.
3. Open the **Actions** tab, then the newest **"Separate songs"** run. When it turns green (about the song's length plus 2 minutes), scroll to **Artifacts** and tap **stems - <song name>** to download a zip.

The default is **Guitar focus**: vocals, drums, bass, lead guitar, rhythm guitar, piano and other, as MP3.
For other options, open **Actions → Separate songs → Run workflow**, enter the file path, and pick the scope and format.

⚠️ This repository is public, so anything you upload here, and the stems, can be seen by other GitHub users.
